# 倒角 (Chamfer) vs 圆角 (Fillet) 判别规则

## 核心区别

| 特征 | 倒角 (Chamfer) | 圆角 (Fillet) |
|------|---------------|--------------|
| 几何形状 | 直线斜面切削 | 圆弧过渡 |
| 边缘线条 | 直线段 | 弧线 |
| 功能 | 去毛刺、便于装配 | 应力消除、流体流动 |

## 标注判别（最可靠）

**圆角标注特征：**
- 以 R 开头：R3、R5、R2.5
- 组标注：2xR3、3-R5

**倒角标注特征：**
- C 形式：C1、C2、C0.5
- D×A 形式：D5xA45、D1.2xA45
- 角度形式：1x45°、2x45°
- 组标注：2-C1、3xC2

## 判断优先级

1. **看标注文字**（最优先）：R 开头 → 圆角，C/D 开头或含角度 → 倒角
2. **看几何轮廓**：弧形边缘 → 圆角，直线斜面 → 倒角
3. **当两者在同一位置重叠（IoU > 0.7）时**：保留标注匹配更好的那个
