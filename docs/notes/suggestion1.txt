  Root causes:                                                                                                                                          
                                                            
  1. Data imbalance — Rare categories have <100 instances (Section View: 11, BOM: 16, Auxiliary View: 45, Threaded Shaft: 59). The model simply doesn't 
  see enough examples to learn them.
  2. Image resolution bottleneck — IMAGE_MAX_TOKEN_NUM=1560 compresses large engineering drawings. Small features (holes, chamfers, thread marks) lose  
  critical visual detail.                                                                                                                               
  3. Task complexity in single output — The model must simultaneously do spatial reasoning (view classification), text reading (size extraction), and
  object detection (features) in one pass. These are cognitively different tasks competing for capacity.                                                
  4. Category confusion — Visually similar categories get conflated: chamfer↔fillet, counterbore↔round hole, pin hole↔round hole. The distinguishing
  cues (thread marks, tolerance codes, dual diameters) are often tiny text.                                                                             
  5. View direction ambiguity — Classifying front/top/left/right views requires understanding projection conventions (1st vs 3rd angle) and relative
  spatial layout — abstract reasoning the model struggles with.
